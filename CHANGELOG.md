# Changelog

All notable changes to the Vera Anchor Verifier SDK for Python are documented here.

The project follows semantic versioning while the public API remains pre-1.0.

## [0.1.0] - 2026-11-XX

Initial public release of the Vera Anchor Verifier SDK for Python.

### Added

- Python implementation targeting verification parity with `@veraanchor/verifier` JavaScript v0.2.0.
- Deterministic Dataset and Ingest verification.
- Public Dataset and Ingest triangulation through Vera Anchor Explorer and Hedera Mirror observations.
- Authorized Dataset and Ingest verification workflows.
- SAGE execution verification and public execution triangulation.
- Independent execution standards verification.
- Verification support for HCS-1, HCS-2, HCS-11, HCS-13, HCS-14, and HCS-26.
- Canonical portable verification reports and deterministic report digests.
- Relying-party verification policies with `allow`, `review`, and `deny` decisions.
- `vera-anchor` command-line interface for verification, report validation, and policy assessment.
- Cross-language JavaScript/Python golden-vector conformance.
- Unit, integration, and live Hedera mainnet conformance coverage.
